# Data Access

The example contains one selected evaluation date, 2026-04-06, for the base scenario. It records hourly load and photovoltaic values, procurement and storage actions, settlement prices, and realized hourly costs for H-DRO, X-PTO, and X-JPO.

The case values are derived from public market and energy series. The upstream sources used by the project are Energy-Charts ([API](https://api.energy-charts.info/)) and Netztransparenz ([website](https://www.netztransparenz.de/)). The example file is a compact derived case record; it does not include the multi-year raw source archives. Users are responsible for observing the upstream providers' current terms when acquiring or redistributing their data.

The load and PV values represent the simulated consumer used in the experiment. Prices are hourly benchmark values and do not represent executable intraday order-book quotes. The single day is illustrative and is not a representative-period estimate.
